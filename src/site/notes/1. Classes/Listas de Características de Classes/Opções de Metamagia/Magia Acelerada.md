*Custo: 2 Pontos de Feitiçaria*

Ao conjurar uma magia que tenha um tempo de conjuração de uma ação, você pode gastar 2 [[1. Classes/Feiticeiro#Nível 2 Fonte de Magia\|Pontos de Feitiçaria]] para alterar o tempo de conjuração para uma [[8. Geral/Combate/Ação Bônus\|Ação Bônus]] para esta conjuração. Você não pode modificar uma magia deste modo se já conjurou uma magia de 1° círculo ou superior no turno atual, nem pode conjurar uma magia de 1° círculo ou superior neste turno após modificar uma magia deste modo.
