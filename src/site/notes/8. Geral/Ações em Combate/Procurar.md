Quando você executa a ação Procurar, realiza um teste de Sabedoria para perceber algo que não é evidente. A tabela Procurar indica quais perícias são relevantes ao executar essa ação, dependendo do que você está tentando detectar.

**Procurar**

| Perícia       | Coisa a Detectar                              |
| ------------- | --------------------------------------------- |
| Intuição      | Estado mental de uma criatura                 |
| Medicina      | Enfermidade de uma criatura ou causa de morte |
| Percepção     | Criatura ou objeto oculto                     |
| Sobrevivência | Comida ou rastros                             |
